# Implementation Plan: DB Storage with Nested Statistics Categories

**Branch**: `react-router` | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/react-router/spec.md`

## Summary

vim-jpコミュニティのプロファイル統計システムを、StreamlitからReact Router + Hono構成へ移行し、Google SheetsからSQLite/D1へデータを移行する。カテゴリの階層構造（2階層まで）をサポートし、ユーザーがドリルダウンで統計を閲覧できるようにする。

## Technical Context

**Language/Version**: TypeScript 5.x
**Primary Dependencies**: React 19, React Router v7, Hono 4.x, Drizzle ORM, TanStack Query
**Storage**: SQLite (開発: better-sqlite3) / Cloudflare D1 (本番)
**Testing**: Vitest
**Target Platform**: Cloudflare Pages (Frontend) + Cloudflare Workers (API)
**Project Type**: Web application (frontend + backend 分離)
**Performance Goals**: 初回読み込み 3秒以内、チャート描画 1秒以内 (Constitution IV準拠)
**Constraints**: キャッシュTTL 5分以上、メモリ 512MB以下
**Scale/Scope**: 回答データ ~1,000件、カテゴリ値 ~50件

**Structure Decision**: Web application (Option 2) を採用。Frontend/Backend を明確に分離し、Cloudflare Pages + Workers で個別デプロイ。IaC はモジュール構成で database/api/frontend を分離管理。

## Key Architecture Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Framework | React Router v7 + Hono | 軽量、Edge 最適化、TypeScript first |
| Database | SQLite / D1 | データ規模に適合、コスト $0 |
| ORM | Drizzle | 型安全、SQLite/D1 対応 |
| Auth | GitHub OAuth + JWT | vim-jp コミュニティ親和性 |
| IaC | Terraform + Cloudflare Provider | 宣言的管理、モジュール構成 |
| CI/CD | GitHub Actions + Cloudflare Pages Git Integration | 自動 Preview デプロイ |
| Linting | oxlint | Rust 製、超高速 |

## Implementation Phases

### Phase 1: Infrastructure Setup
- Terraform モジュール実装 (database, api, frontend)
- GitHub Actions CI/CD パイプライン
- D1 スキーママイグレーション (Wrangler)

### Phase 2: API Implementation
- Hono API ルート実装 (categories, responses, statistics, auth)
- Drizzle ORM スキーマ・クエリ
- GitHub OAuth 認証フロー

### Phase 3: Frontend Implementation
- React Router v7 ルーティング
- TanStack Query データフェッチ
- Plotly.js チャートコンポーネント
- 認証 UI (ログイン/ログアウト)

### Phase 4: Data Migration
- Google Sheets → D1 マイグレーションスクリプト
- データ検証・整合性チェック

### Phase 5: Testing & Polish
- E2E テスト
- パフォーマンス最適化
- ドキュメント整備
